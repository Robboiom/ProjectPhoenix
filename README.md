# Project Phoenix

Project Phoenix is a beginner-focused fitness application developed as my final-year Software Engineering project at the University of Chester.

## Features

- Exercise library
- Custom workout routine creation
- Workout tracking
- Meal logging
- Macronutrient calculation
- Fitness guidance for beginner gym users

## Technologies

- Swift
- SwiftUI
- SwiftData
- Xcode

## Project Aim

The aim of Project Phoenix was to create an accessible fitness application for beginner gym users, helping them plan routines, track workouts, record meals and access simple fitness guidance.

## Development

The application was designed and developed as part of my BSc (Hons) Software Engineering degree.

It was developed primarily for iPad using Swift and SwiftUI.
